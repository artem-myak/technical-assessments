# ⚽ Bundesliga Player Analytics: SQL Case Study

## 📋 Огляд проєкту
Цей проєкт присвячений поглибленому аналізу ринку футболістів німецької Бундесліги. Основна мета — перетворити сирі дані про гравців у стратегічні інсайти для скаутингу, фінансового планування та оцінки ризиків складів.

Аналіз фокусується на трьох ключових напрямках:
1.  **Фінансові ризики**: Концентрація вартості активів та управління контрактами.
2.  **Командна стабільність**: Зіграність складів та динаміка підписання нових гравців.
3.  **Еволюція гравця**: Визначення пікових фаз ринкової вартості.

## 🛠 Технологічний стек
*   **DBMS**: ClickHouse Cloud (висока продуктивність на великих обсягах даних).
*   **Data Source**: [Bundesliga Soccer Player Dataset (Kaggle)](https://www.kaggle.com/datasets/oles04/bundesliga-soccer-player).
*   **SQL Techniques**: Віконні функції (Window Functions), Common Table Expressions (CTE), складні агрегації, аналіз частотних розподілів (мода, медіана).

## 🚀 Ключові аналітичні задачі та рішення

### 1. Управління ризиками складів (Squad Stability)
Було розроблено алгоритм "черги на вибуття", який ідентифікує клуби, що найближчим часом зіткнуться з необхідністю заміни критичної маси гравців (5 і більше осіб).
*   **Рішення**: Багаторівневе ранжування термінів контрактів.

### 2. Аналіз "Піку вартості" (Career Path Analysis)
Замість стандартних середніх значень, було застосовано аналіз індивідуальних історичних піків (`max_price`).
*   **Інсайт**: Визначено вік, у якому гравець Бундесліги найімовірніше досягає своєї максимальної ринкової оцінки. Це критично для прийняття рішень про перепродаж активів.

### 3. Концентрація вартості (Financial Concentration)
Ідентифіковано клуби, де понад 50% загальної вартості складу припадає лише на трьох гравців.
*   **Метод**: Розрахунок Top-3 Concentration Ratio через віконні агрегації. Це підкреслює високу залежність результатів клубу від здоров'я та лояльності обмеженого кола лідерів.

### 4. Зіграність (Team Cohesion)
Оцінено стабільність команд через медіанний час перебування гравців у структурі клубу.
*   **Методологія**: Використано медіану замість середнього арифметичного для усунення впливу ветеранів-аутлаєрів на загальну статистику.

## 📈 Оптимізація та точність
Під час виконання проєкту було впроваджено ряд технічних оптимізацій:
*   **Window Frames**: Використання `ROWS BETWEEN 1 FOLLOWING` для точного підрахунку послідовних підписань навіть за наявності ідентичних дат.
*   **Performance**: Оптимізація `GROUP BY` у ClickHouse через використання функцій `any/max` для неагрегованих колонок.
*   **Data Integrity**: Пошук "тезок" всередині клубів через маніпуляції з рядковими функціями для покращення якості внутрішньої ідентифікації.
